# Booking Calendar Heatmap

A React (Vite) single-page app that visualizes hotel bookings as an occupancy heatmap calendar.

## 🔗 Live Demo

https://booking-calendar-t419.onrender.com/

---

## ⚙️ Run Locally

```bash
npm install
npm run dev
```

---

## 🧩 Features

* Month-view calendar (6-week grid)
* Occupancy heatmap (0–10 rooms)
* Month navigation (Prev / Next / Today)
* Drag-to-select date range (forward & backward)
* Booking details panel (range-based)
* Correct booking logic:

  * Check-in inclusive
  * Check-out exclusive
  * Cancelled bookings ignored

---

## 🛠 Tech Stack

* React (Vite)
* Tailwind CSS
* Native Date API

---

## 📦 Deployment

* Build: `npm run build`
* Output: `dist/` (used for Render)
